# Design system

Download placement: completed results sit above the uploader, configuration and preview grid. Each newly completed operation scrolls that section into view and focuses its heading. A single result gets a primary Download button; a batch gets a primary Download all as ZIP action. Mobile always shows the Download label and uses full-width buttons. Current results appear first, with earlier session results preserved in a collapsed Previous results section. The standalone workspace also prioritizes downloads above source files.

Visual reference: design-concept.png, generated using the built-in image tool. Prompt: clean white FilePilot productivity app, navy Inter typography, teal accents, slim top navigation, left-aligned hero, document stack illustration, privacy separator, searchable category-filtered tool catalog, compact footer. No invented metrics or testimonials. All UI is real HTML/CSS; no screenshot used as interface.

Color lock: white background, navy #10213b foreground, muted slate #59677b, teal #087f75 primary, #dce3e9 borders. Dark mode uses #101925 background, #182331 surfaces, #eef4fa text and mint #6bdfcb action accents. Semantic PDF coral, image teal, batch blue accents use tokens. Inter is self-hosted. Spacing 4/8/12/16/24/32/48/64; radii 8/12/16. Main content maximum 1280px. Buttons minimum 44px. Focus outlines are visible. Reduced motion disables transitions. Mobile navigation is an accessible Radix dialog.

Navigation update: use direct Merge PDF/Split PDF links, a two-column Convert disclosure (to/from PDF, plus image formats), and a wider All Tools disclosure grouped by Organize PDF, Convert files, Edit images and Batch tools. Flyouts use existing surface/border/shadow tokens, compact colored icons, uppercase section labels and a footer link. Only supported tools are listed. Open on hover or click; keyboard users can use Enter/Space, ArrowDown, Tab and Escape. Escape restores focus to the trigger. Outside click, focus exit and route changes dismiss the flyout. Mobile retains the category links and adds grouped direct tool links in a scrollable dialog.
